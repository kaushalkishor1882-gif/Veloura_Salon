## 📸 Project Overview

**Veloura Salon** is a professional, luxury-grade beauty salon website built for a real local business in **Ranchi, Jharkhand**. It is designed to attract customers, showcase services, and generate bookings — just like a big brand's website.

This project was built as part of the **Future Interns Full Stack Web Development Task 3**, with the goal of creating a real, deployable business website rather than an imaginary one.

## 🎨 Design Choices

- **Fonts:** Cormorant Garamond (serif display) + Jost (clean sans-serif)
- **Color Palette:**
  - Background: `#080808` (deep black)
  - Gold accent: `#c9a96e`
  - Text: `#f5f0e8` (warm white)
- **Style:** Luxury dark — inspired by high-end beauty brands like Chanel, Dior Beauty
- **Animations:** Pure CSS + Vanilla JS (no heavy libraries)

---

## 🛠️ Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, Grid, Flexbox, keyframe animations
- **Vanilla JavaScript** — No frameworks, pure JS for all interactions
- **Google Fonts** — Cormorant Garamond + Jost
- **SVG** — Custom hand-crafted vector images

## 📋 Sections Included

1. **Navbar** — Fixed, scroll-aware with mobile hamburger menu
2. **Hero** — Full-screen with floating 3D card, stats, CTA buttons
3. **Marquee** — Gold scrolling services ticker
4. **Services** — 6 service cards with SVG icons and hover effects
5. **About** — Story, features, decorative art panel
6. **Pricing** — 3 pricing tiers (Essential / Premium / Bridal)
7. **Gallery** — Grid layout (replace with real salon photos)
8. **Testimonials** — 3 client review cards
9. **Contact** — Info panel + full booking form
10. **Footer** — 4-column with all links and WhatsApp CTA

## 📝 Customization Guide

| What to change | Where |
|---|---|
| Phone number | `index.html` — search `9999999999` |
| WhatsApp link | `index.html` — search `wa.me/91` |
| Location | `index.html` — contact section |
| Salon name | `index.html` — all `Veloura` references |
| Gallery photos | Replace `images/` SVGs with real `.jpg/.png` photos |
| Pricing | `index.html` — pricing section `₹` values |
| Colors | `style.css` — `:root` CSS variables |
| Fonts | `index.html` — Google Fonts link + `style.css` font-family |
